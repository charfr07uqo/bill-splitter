# Images d'Exemple pour les Tests

Ce dossier contient des images d'exemple pour tester l'application Bill Splitter.

## Comment ajouter des images d'exemple

1. **Placez vos images** dans ce dossier `public/samples/`
2. **Nommez vos fichiers** de manière descriptive (ex: `restaurant_invoice.jpg`, `supermarket_receipt.jpg`)
3. **Formats supportés** : JPG, PNG, WebP
4. **Taille recommandée** : 800x600px minimum pour de meilleurs résultats

## Utilisation dans l'application

Les images placées dans ce dossier apparaissent automatiquement dans le sélecteur d'images d'exemple de l'application. Cliquez sur une image pour la charger et lancer l'analyse avec Gemini.

## Conseils pour de bonnes images de test

- **Éclairage** : Assurez-vous que le texte est bien lisible
- **Angle** : Photographiez les factures à plat pour éviter les déformations
- **Résolution** : Utilisez une résolution suffisante pour que le texte soit net
- **Format** : Préférez les formats numériques modernes aux anciennes factures thermiques

## Exemples d'images à ajouter

- Factures de restaurants
- Tickets de caisse de supermarchés
- Reçus de stations-service
- Factures de services (téléphone, internet, etc.)
- Tickets de parking ou transport
